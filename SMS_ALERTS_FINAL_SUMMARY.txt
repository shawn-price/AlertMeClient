PHONE RESOLUTION STRATEGIES
================================================================================

STRATEGY 1: EXPLICIT_PHONE (Banks)
  └─ Uses direct phone field if available
  └─ Falls back to account-to-phone conversion if needed
  └─ Skips if no phone found

STRATEGY 2: ACCOUNT_TO_PHONE (Mobile Wallets)
  └─ Tries explicit phone field first
  └─ Converts 10-12 digit account numbers to phone format
  └─ Example: "0801234567" → "+2348012345 67"

STRATEGY 3: NO_PHONE (Payment Platforms)
  └─ Skips beneficiary SMS entirely
  └─ No error thrown - graceful degradation
  └─ Only sender debit alert sent

KEY FEATURES
================================================================================

✅ SENDER SMS (Required)
   - Always attempted after successful transaction
   - Includes debit amount and balance
   - Reference number and timestamp included
   - Bank-branded SMS template used
   - Retry 3 times if failed (exponential backoff)

✅ BENEFICIARY SMS (Optional)
   - Sent when phone is available
   - Includes credit amount and transaction reference
   - Sender name included
   - Platform-aware resolution
   - Skipped gracefully if phone unavailable

✅ ERROR HANDLING
   - Network errors: Automatic retry (3x)
   - Invalid phone: Skip with logging
   - Platform not supported: Skip with logging
   - Never blocks transaction completion

✅ VALIDATION
   - Nigerian phone numbers only
   - Accepts 3 formats: +234XXX, 0XXX, 234XXX
   - 10+ digit requirement
   - Account-to-phone length validation (10-12 digits)

✅ LOGGING & MONITORING
   - Phone resolution logged
   - Each SMS attempt logged
   - Skip reasons logged
   - Error categorization logged
   - All events trackable

USAGE EXAMPLE
================================================================================

// In TransactionSuccessScreen:
const alertResult = await productionAlerts.sendTransactionAlert({
  type: "debit",
  senderName: userData.name,
  senderBank: transferData.bank,
  senderPhone: userData.phone,
  recipientName: transferData.beneficiaryName,
  recipientBank: transferData.bank,
  recipientPhone: transferData.phone,
  recipientAccountNumber: transferData.accountNumber,
  amount: parseFloat(transferData.amount),
  balance: userData.balance,
  reference: transactionId,
  platformName: transferData.bank,  // ← Platform-aware resolution
})

// Result handling:
if (alertResult.success) {
  console.log('✅ Debit SMS sent')
  if (alertResult.creditAlertSent) {
    console.log('✅ Credit SMS sent')
  } else if (alertResult.creditAlertSkipped) {
    console.log('⏭️  Credit SMS skipped:', alertResult.creditSkipReason)
  }
}
